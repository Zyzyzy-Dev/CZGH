# ✎ 创作规划 0.5.0｜SillyTavern 扩展

想让一个模型先做写作规划，再交给另一个模型写正文？「创作规划」把这两个阶段分开了：

**发送消息 → 生成规划 → 自动或手动继续正文。**

## 可以做什么？
- **独立配置规划**：规划使用自己的 API、模型、预设和世界书开关，不修改酒馆正文配置。
- **保存方案**：预设、世界书及 API 方案可保存和切换；支持柏宝箱预设分组，关闭分组仍保留组内条目的开关。
- **实时查看规划**：可开启流式输出，在最新用户消息下查看规划进度和错误。
- **控制正文时机**：默认规划完成后自动继续；也可关闭自动正文，检查规划后再点击气泡按钮生成正文。
- **查看发送上下文**：眼睛按钮打开预览，支持预计输入 tokens 和同类消息合并展示。
- **调整提示词和界面**：内置规划提示词、正文注入提示词可编辑及恢复默认；支持日间／夜间／自适应外观、窗口缩放。

## 安装
酒馆「扩展 → 安装扩展」中粘贴：
https://github.com/Zyzyzy-Dev/CZGH

安装后刷新页面，从魔法棒菜单打开「创作规划」。先配置规划 API、预设和世界书，再开启「启用创作规划」。新建／覆盖 API 方案后，接口和附加参数才会保存。

## 使用前看一下
- 规划会额外调用一次 API，增加等待时间及相应接口用量。
- 以单角色文本聊天为主要范围；群聊、附件、部分世界书位置及宏尚未完整支持。MVU/EJS 兼容范围请看 README。
- 插件能检查规划标签，但不能保证模型不遗漏步骤，也不能保证正文执行所有要求。
- 手动等待时酒馆可能仍显示生成中，但正文 API 尚未调用；点击「生成正文回复」才继续。
- 关闭面板不会停止生成。规划期间用插件停止；正文开始后用酒馆停止。
- 新填的密钥保存在当前浏览器，换浏览器或清除网站数据后可能需要重填。不要同时启用 CZGHCS 测试版和正式版。
