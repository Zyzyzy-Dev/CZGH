# 创作规划 0.5.2 更新公告

本次汇总从 0.5.0 到 0.5.2 的更新。

**新增**

- 新增「数据库」记忆兼容。开启后，规划可以读取数据库导出到世界书的记忆：使用编码召回时，等编码写入后读取对应的详细纪要；没有编码召回时，自动筛选最多 25 条相关纪要。世界书来源统一在插件的世界书页面管理。
- 世界书页面新增「聊天附加世界书」栏目，方便查看和调整当前聊天使用的世界书。

**修复**

- 修复反复切换预览和设置后，无法返回预设或世界书页面的问题。
- 修复修改设置后列表跳回顶部的问题，保留滚动位置、展开状态和正在编辑的位置。
- 修复高级设置中控件重叠，以及部分聊天附加世界书无法正确显示和读取的问题。

**优化**

- 优化预设条目和分组开关的响应，减少手机端与电脑端操作时的卡顿，连续切换更顺畅。
- 更新默认规划提示词和正文衔接提示词，更明确规划依据和交接要求；旧默认内容自动更新，自定义内容保留。
- 简化数据库兼容设置，只需开启「数据库」，无需另选读取模式、来源或数量。
